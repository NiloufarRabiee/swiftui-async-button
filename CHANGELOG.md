# Changelog

All notable changes to this project will be documented here.

## Unreleased

### Added

- Reusable SwiftUI async button.
- Automatic loading state.
- Double-tap prevention while an action is running.
- Support for throwing async actions.
- Optional success state and custom system image.
- Optional error callback.
- Configurable minimum loading duration.
- Configurable success display duration.
- iOS and macOS support.
- Swift Package Manager support.
- Unit tests and GitHub Actions CI.

# Security Policy

This package provides a local SwiftUI button component for asynchronous actions. It does not perform networking, persistence, analytics, authentication, or credential handling on its own.

Applications using the async action closure are responsible for securely handling their own requests, credentials, user data, and error reporting.

For security-relevant issues, contact the repository owner privately through the contact information available on their GitHub profile.

Use GitHub Issues for ordinary bugs and feature requests.
